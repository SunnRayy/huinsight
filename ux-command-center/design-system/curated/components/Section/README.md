# Section

A titled group: optional Icon, uppercase eyebrow and a 14px bold title on the left, a `right` slot (link, button, select) on the right, then `children`. Also exports **SectionTitle**, the same header row (with 16px bottom margin) for the top of a Card.

**Use** SectionTitle inside Cards and Section for page bands outside cards. Right-slot links are `color-primary`, 11px, ending in "→".

**Consumer provides:** `title` and/or `eyebrow`, `icon`, `right`, `children`. Source: `components/operations/Section.tsx`.
